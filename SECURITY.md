# Security Policy

## Reporting Security Issues

Gumnut takes security seriously, and encourages you to report
any security vulnerability promptly so that appropriate action can be taken.

To report a security issue in this SDK or in Gumnut's services, please contact Gumnut at <hello@gumnut.ai>. Gumnut's security policy is at <https://www.gumnut.ai/security>.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us
maintain the security of our SDKs. If you believe you have found a security
vulnerability, please adhere to responsible disclosure practices by allowing us
a reasonable amount of time to investigate and address the issue before making
any information public.

---

Thank you for helping us keep the SDKs and systems they interact with secure.
